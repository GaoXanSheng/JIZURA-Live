Studio Cursor: Mono cursor pack for Windows
https://studiocursor.com/cursors/mono/

WHAT IS IN THIS FOLDER
  17 cursors: 15 still cursors (.cur) and 2 animated cursors (.ani).
  Each file holds the cursor at 32, 48, 64 and 128 px, so it stays sharp
  when you make the pointer bigger. install.inf adds the set to Windows.

INSTALL
  1. Unzip this folder somewhere you can find it again.
  2. Right-click install.inf and choose Install. On Windows 11, choose
     "Show more options" first. Accept the administrator prompt: Windows
     copies the files to C:\Windows\Cursors\Studio Cursor Mono.
  3. Open Settings > Bluetooth & devices > Mouse > Additional mouse settings.
  4. On the Pointers tab, pick "Studio Cursor Mono" under Scheme and press Apply.

OR SET THE CURSORS BY HAND
  On the Pointers tab, select a role, click Browse and pick the matching
  file below. Repeat for each role, then click Save As to keep the set.

  Normal Select........... arrow.cur
  Help Select............. help.cur
  Working in Background... appstarting.ani
  Busy.................... wait.ani
  Precision Select........ crosshair.cur
  Text Select............. ibeam.cur
  Handwriting............. nwpen.cur
  Unavailable............. no.cur
  Vertical Resize......... sizens.cur
  Horizontal Resize....... sizewe.cur
  Diagonal Resize 1....... sizenwse.cur
  Diagonal Resize 2....... sizenesw.cur
  Move.................... sizeall.cur
  Alternate Select........ uparrow.cur
  Link Select............. hand.cur
  Location Select......... pin.cur
  Person Select........... person.cur

GO BACK TO THE WINDOWS CURSORS
  Pointers tab > Scheme > Windows Default (system scheme) > Apply.
